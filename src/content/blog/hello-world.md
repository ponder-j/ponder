欢迎来到我的个人网站！这是我的第一篇文章。

## 这个网站是怎么来的

这个网站使用 [Astro](https://astro.build) 构建：一个专注于内容的静态站点框架。它的好处是：

- 页面默认零 JavaScript，打开速度快；
- 用 Markdown 写文章，格式简单；
- 构建后输出纯静态文件，可以部署到任何地方，包括免费的 GitHub Pages。

## 如何添加一篇文章

写文章很简单：在 `src/content/blog/` 目录下新建一个 `.md` 文件，在开头加上如下格式的元信息（frontmatter）：

```md
---
title: "我的新文章"
description: "一句话介绍这篇文章。"
pubDate: 2026-08-18
tags: ["标签一", "标签二"]
---

这里是正文，用 Markdown 写即可。
```

保存后，文章会自动出现在博客列表里。就是这么简单。

> 提示：把 `draft: true` 加到 frontmatter 里，可以暂时隐藏一篇文章不发布。

## 接下来做什么

去 [项目页](../../projects/) 看看，或者到「关于」页面了解一下我。也可以直接去改 `src/config.ts`，把网站上的名字、介绍、链接都换成你自己的。
